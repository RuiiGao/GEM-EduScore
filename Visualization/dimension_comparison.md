# GEM-EduScore Dimension Comparison Report V0.1


# 1. Overview


## Comparison Objects


Current Practice:

JLU-CP 2025 Education Portfolio


Benchmark Practice:

HK-United 2024 Education Portfolio



## Purpose


This document converts GEM-EduScore evaluation results and benchmark analysis into a visual comparison structure.


The purpose is to identify:


- Current strengths;
- Evidence gaps;
- Improvement opportunities.



This comparison is not a ranking system.

It is an educational improvement analysis tool.



---

# 2. Evaluation Dimensions


The comparison follows GEM-EduScore 10-dimension Rubric.


## D1 Goal & Audience Alignment


Focus:

Whether the Education practice has clear goals and appropriate audience adaptation.



JLU-CP:

Current Status:

Medium-Strong


Strengths:

- Clear education objectives;
- Multiple target groups;
- Diverse educational activities.


Evidence Gap:

- Limited systematic audience research.



Benchmark Reference:

HK-United demonstrates:

- Audience segmentation;
- Different education strategies for different groups.



Improvement Direction:

Conduct audience analysis before activity design.
