# GEM-EduScore System Architecture V0.1


# 1. System Overview


GEM-EduScore is an LLM-based Education Practice Evaluation Framework.

The system transforms unstructured Education materials into:

- Structured evidence;
- Education quality evaluation;
- Benchmark comparison;
- Improvement recommendations.


The framework integrates:

- Evidence Extraction;
- Rubric Evaluation;
- Benchmark Intelligence;
- Recommendation Generation.



---

# 2. Overall Architecture


The complete system architecture:


Education Materials

(Wiki Pages / Activity Reports / Education Summaries)

↓

Input Processing Layer

↓

Evidence Extraction Module

↓

Education Evidence Profile

↓

Rubric Evaluation Module

↓

Education Evaluation Report

↓

Benchmark Analysis Module

↓

Benchmark Comparison

↓

Improvement Recommendation

↓

Visualization Dashboard

# 3. System Components


# Component 1: Input Processing Layer


## Purpose


Convert different Education materials into standardized inputs.



## Input Sources


Including:


- iGEM Education Wiki;
- Activity descriptions;
- Education reports;
- Teaching materials.



## Output


Structured Education Input:


Example:

JLUCP_input.md



---

# Component 2: Evidence Extraction Module


## Purpose


Extract educational evidence from unstructured text.



## Main Functions


Identify:


- Education goals;
- Target audience;
- Activity design;
- Teaching methods;
- Interaction;
- Evaluation evidence;
- Accessibility;
- Sustainability;
- Ethics.



## Core Principle


No Evidence → No Claim



## Output


Evidence Profile

D5 Feedback & Iteration

# 5. Core Innovation


## 5.1 Evidence-driven Evaluation


The system does not directly judge Education activities.

Instead:


Material

↓

Evidence

↓

Evaluation



This improves transparency and reliability.



---

## 5.2 Benchmark-guided Improvement


The system does not only answer:


"How good is this activity?"


It also answers:


"How can this activity become better?"



---

## 5.3 Reusable Education Intelligence


Excellent Education practices are transformed into structured knowledge.

Future teams can learn:

- Effective teaching methods;
- Evaluation strategies;
- Resource design patterns.
