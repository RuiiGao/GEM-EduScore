# GEM-EduScore Skill V1.0


# 1. Skill Overview


## Name


GEM-EduScore


## Purpose


GEM-EduScore is an LLM-based Education Practice Evaluation Skill designed to analyze, evaluate, compare, and improve Education activities.


The Skill transforms unstructured Education materials into:


- Structured evidence;
- Education quality evaluation;
- Benchmark comparison;
- Improvement recommendations.



---

# 2. Core Capability


GEM-EduScore provides four major capabilities:


## Capability 1

Evidence Extraction


Extract important educational information from raw materials.


Including:


- Education goals;
- Target audience;
- Activity design;
- Teaching methods;
- Interaction;
- Evaluation evidence;
- Accessibility;
- Sustainability;
- Ethics.



---

## Capability 2

Rubric Evaluation


Evaluate Education practices based on GEM-EduScore Rubric.


Evaluation dimensions:


D1 Goal & Audience Alignment

D2 Education Design Quality

D3 Learning Interaction

D4 Educational Outcome Assessment

D5 Feedback & Iteration

D6 Documentation & Reusability

D7 Participant Empowerment

D8 Accessibility & Inclusivity

D9 Sustainability

D10 Ethics & Responsibility



---

## Capability 3

Benchmark Analysis


Analyze excellent Education practices.


Extract:


- Successful design patterns;
- Reusable strategies;
- Evidence collection methods;
- Educational innovation features.



---

## Capability 4

Improvement Recommendation


Generate actionable suggestions based on:


Current Practice

+

Benchmark Comparison


Output:


- Strengths;
- Weaknesses;
- Improvement priorities;
- Future strategies.

# 4. Execution Workflow


The Skill follows a four-stage pipeline.



# Stage 1: Evidence Understanding


Input:

Education Material


Process:


Education Material

↓

Evidence Extraction


Use:

Evidence Schema

+

Evidence Extractor Prompt



Output:


Structured Evidence Profile



---

# Stage 2: Education Evaluation


Input:


Evidence Profile


Process:


Apply GEM-EduScore Rubric



Output:


Education Evaluation Report



Including:


- Dimension analysis;
- Strengths;
- Evidence gaps.



---

# Stage 3: Benchmark Comparison


Input:


Evaluation Result

+

Benchmark Feature Profile


Process:


Compare current practice with benchmark characteristics.



Output:


Gap Analysis



Including:


- Similarities;
- Differences;
- Missing elements.



---

# Stage 4: Improvement Generation


Input:


Gap Analysis


Process:


Generate optimization strategies.



Output:


Improvement Recommendation Report



---

# 6. Operating Principles


## Principle 1

Evidence First


The Skill must prioritize evidence-supported analysis.


Rule:


No Evidence → No Claim



---

## Principle 2

Separate Description and Evaluation


The Skill should distinguish:


What happened?


and


Why it is valuable?



---

## Principle 3

No Unsupported Ranking


The Skill should not:


- Rank teams;
- Predict awards;
- Claim official evaluation results.



---

## Principle 4

Focus on Improvement


The purpose is:


Not:

Judge Education activities.


But:


Improve Education practices.
