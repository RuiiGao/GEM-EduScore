# GEM-EduScore Rubric V0.1

## 1. Rubric 定位

本 Rubric 用于 GEM-EduScore 对 iGEM Education 活动进行辅助诊断。

它参考 iGEM Best Education 的评价理念，并进一步将 Education 中的目标、教学设计、互动、Evidence、Reuse、Inclusivity 等内容操作化。

> 本 Rubric 是 GEM-EduScore 自建诊断量表，并非 iGEM 官方评分表。

---

# 2. 总体输出

系统输出两个核心指标。

## Education Design Score

评价活动设计：

> **0–100**

## Evidence Coverage

评价当前材料能够多充分地支持这些判断：

> **0–100%**

两者分开计算。

---

# 3. Master Scale

所有维度首先采用统一 1–6 分：

| 分数 | 含义                                         |
| ---- | -------------------------------------------- |
| 1    | 缺失或几乎没有相关设计                       |
| 2    | 有初步涉及，但非常有限                       |
| 3    | 已形成基本做法                               |
| 4    | 设计较完整且实际执行                         |
| 5    | 已形成较强评价、反馈或闭环                   |
| 6    | 表现突出，并体现深度参与、迭代、推广或持续性 |

# 4. Education Design Rubric

## D1｜目标与受众匹配｜8%

判断：

- 教育目标是否明确；
- 目标人群是否明确；
- 内容和形式是否针对该人群调整。

| 分数 | 标准                             |
| ---- | -------------------------------- |
| 1    | 没有明确目标或受众               |
| 2    | 明确受众，但基本没有适配         |
| 3    | 有基本目标并进行部分适配         |
| 4    | 目标、受众、内容和形式有清晰对应 |
| 5    | 有调研或反馈支持受众适配         |
| 6    | 受众需求持续影响甚至参与活动设计 |

---

## D2｜教学设计质量｜12%

判断：

- 是否有完整教学流程；
- 是否围绕教育目标展开；
- 是否形成知识—实践—应用联系。

| 分数 | 标准                            |
| ---- | ------------------------------- |
| 1    | 活动结构零散                    |
| 2    | 主要是单向讲授                  |
| 3    | 有多个环节，但连接较弱          |
| 4    | 目标—知识—活动—任务形成合理逻辑 |
| 5    | 形成完整学习链，实践能深化理解  |
| 6    | 教学链高度完整，并能动态调整    |

---

## D3｜双向学习与互动｜14%

判断：

- 学生是否主动参与；
- 是否有讨论、实践、制作、展示；
- 学生反馈是否真正被接收。

| 分数 | 标准                                   |
| ---- | -------------------------------------- |
| 1    | 完全单向输出                           |
| 2    | 只有简单问答                           |
| 3    | 有小游戏、任务、小组活动或较多问答     |
| 4    | 有讨论、实践、学生作品或展示           |
| 5    | 学生反馈实际影响活动设计或实施         |
| 6    | 参与者参与共同设计、共同创造或持续合作 |

---

## D4｜教育效果评价与证据｜14%

判断：

- 是否存在问卷、访谈、前后测；
- 是否保存学生作品或行为记录；
- 数据是否对应教育目标。

| 分数 | 标准                                   |
| ---- | -------------------------------------- |
| 1    | 只有“效果很好”等主观描述               |
| 2    | 只有人数、照片等活动发生证据           |
| 3    | 有满意度、现场反馈或简单问卷           |
| 4    | 有与教育目标对应的系统评价             |
| 5    | 有明确前后变化或多种证据互证           |
| 6    | 评价系统完整，并用于解释效果和改进活动 |

---

## D5｜反馈与迭代｜12%

| 分数 | 标准                                       |
| ---- | ------------------------------------------ |
| 1    | 没有反馈                                   |
| 2    | 只有非正式反馈                             |
| 3    | 正式收集问卷、访谈或建议                   |
| 4    | 对反馈进行整理分析                         |
| 5    | 反馈明确改变下一轮活动                     |
| 6    | 形成“实施→反馈→修改→再实施→再验证”完整循环 |

---

## D6｜文档化与可复用性｜12%

判断是否留下：

- PPT；
- 教案；
- Worksheet；
- Protocol；
- 活动流程；
- 注意事项；
- 本地化建议。

| 分数 | 标准                                  |
| ---- | ------------------------------------- |
| 1    | 只有简单活动描述                      |
| 2    | 留下少量展示资料                      |
| 3    | 有基本流程或教学材料                  |
| 4    | 其他团队基本能够复现                  |
| 5    | 有完整材料、实施说明和经验总结        |
| 6    | 已被实际复用，或提供不同人群/地区变体 |

---

## D7｜参与者赋能与 SynBio 参与｜10%

判断参与者是否从“知道”进一步发展到：

- 提问；
- 设计；
- 实践；
- 创作；
- 持续参与 Synthetic Biology。

| 分数 | 标准                                         |
| ---- | -------------------------------------------- |
| 1    | 只有宣传或信息接触                           |
| 2    | 获得基础知识                                 |
| 3    | 参与简单实践或任务                           |
| 4    | 能自主完成设计、讨论或科学实践               |
| 5    | 能形成自己的问题、观点、设计或成果           |
| 6    | 形成持续参与、共同创造、社区贡献或新教育行动 |

---

## D8｜公平性与可及性｜8%

判断是否考虑：

- 年龄；
- 知识背景；
- 教育资源；
- 地理位置；
- 网络设备；
- 语言；
- 身体障碍；
- 参与成本。

| 分数 | 标准                                       |
| ---- | ------------------------------------------ |
| 1    | 完全没有考虑                               |
| 2    | 有提及但没有实际措施                       |
| 3    | 实施基本适配                               |
| 4    | 明确降低目标群体参与门槛                   |
| 5    | 主动覆盖资源不足或特殊群体                 |
| 6    | 公平与可及性成为核心设计原则并形成推广方案 |

---

## D9｜持续性与长期影响｜5%

| 分数 | 标准                                     |
| ---- | ---------------------------------------- |
| 1    | 完全一次性                               |
| 2    | 仅表示未来希望继续                       |
| 3    | 提供后续资源或联系方式                   |
| 4    | 有连续活动、长期资源或跟踪               |
| 5    | 有稳定合作、周期性开展或社区维护         |
| 6    | 形成能够长期运行甚至脱离原团队存在的机制 |

- 社会影响；
- 公平；
- 隐私；
- 科研责任；
- 生物伦理；
- AI伦理。

| 分数 | 标准                               |
| ---- | ---------------------------------- |
| 1    | 完全没有                           |
| 2    | 简单提醒风险                       |
| 3    | 正式介绍伦理问题                   |
| 4    | 有案例、情境讨论或反思             |
| 5    | 参与者主动比较不同立场并论证       |

# 6. Education Design Score

每个维度先将 1–6 分标准化：

**Normalized Score = (Score - 1) / 5**

然后：

**Dimension Score = Normalized Score × Weight**

例如：

D3 = 5/6

则：

```text
(5 - 1) / 5 = 0.8
0.8 × 14 = 11.2
```

所以 D3 贡献：

> **11.2 / 14**

十个维度相加得到：

> **Education Design Score / 100**

因此：

1分 → 0%  
6分 → 100%

# 7. Evidence Strength

每个维度同时评价证据强度。

## E0｜No Evidence

没有有效证据。

数值：

> 0

## E1｜Weak Evidence

例如：

- 主观描述；
- 活动照片；
- “学生很喜欢”。

数值：

> 0.33

## E2｜Moderate Evidence

例如：

- 正式问卷；
- 学生作品；
- 反馈记录；
- 访谈；
- 明确活动记录。

数值：

> 0.67

## E3｜Strong Evidence

例如：

- 前后测；
- 可核查统计数据；
- 多来源互证；
- 明确反馈—修改—再次实施记录。

数值：

> 1.00

# 8. Evidence Coverage

Evidence Coverage measures how sufficiently the available material supports the evaluation conclusions.

It is independent from Education Design Score.

A high-quality activity may receive:

High Education Design Score
+
Low Evidence Coverage

when the design appears strong but documentation is insufficient.

---

## Evidence Coverage Levels

### E0 — No Evidence

No supporting evidence exists.

Value:

0


### E1 — Weak Evidence

Examples:

- subjective descriptions;
- activity photos;
- statements such as "students enjoyed the activity".

Value:

0.33


### E2 — Moderate Evidence

Examples:

- formal questionnaires;
- student works;
- interviews;
- feedback records;
- documented implementation records.

Value:

0.67


### E3 — Strong Evidence

Examples:

- pre/post tests;
- verifiable quantitative data;
- multiple evidence sources;
- documented feedback-modification-reimplementation cycle.

Value:

1.00


---

## Calculation Principle

Evidence Coverage is calculated based on:

Evidence Strength × Dimension Weight

The final output is:

Evidence Coverage / 100%

For prototype implementation, LLM may provide an estimated Evidence Coverage value.

Future versions may implement automatic calculation.

# 9. Context Metrics

以下指标只提取，不直接进入100分：

- Participants
- Audience Groups
- Age
- Duration
- Activity Type
- Number of Schools
- Cities / Regions
- Online Reach
- Offline Reach
- Number of Sessions
- Budget
- Collaborating Organizations

这些数据主要用于：

> **Benchmark Matching**

而不是直接代表 Education Quality。

# 10. Plan Mode规则

策划案中已经明确设计的环节标记为：

`Planned`

不能因为活动尚未实施直接按最低分处理。

例如：

> “活动后计划进行问卷。”

可认为：

`Feedback Mechanism: Planned`

但不能认为：

`Feedback Result: Observed`

---

# 11. Review Mode规则

活动总结或 Wiki 只评价材料能够证明已实施的内容。

例如：

> “原计划进行前后测。”

但没有说明是否真正执行，

则：

`Pre/Post Test: Not Evidenced`

每一个维度统一输出：

```text
Dimension:
D3 双向学习与互动

Score:
5 / 6

Evidence Strength:
E2

Evidence:
- 原文证据1
- 原文证据2

Reason:
参与者不仅进行了讨论和实践，
其反馈还影响了后续活动设计，因此达到5分。

Why Not Higher:
未发现参与者参与共同设计或长期共同创造的证据。

Improvement:
下一轮活动可邀请部分目标参与者提前参与课程设计，
并记录其建议如何影响最终活动。
```

# 13. 核心判断原则

> **No Evidence → No Claim**

> **Reach ≠ Engagement**

> **Activity Happened ≠ Education Worked**

> **Good Writing ≠ Strong Evidence**

> **High Budget ≠ High Education Quality**

> **AI Score ≠ Official iGEM Score**
